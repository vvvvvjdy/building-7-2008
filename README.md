# 消失在2008的7号楼

以 2008 年旧电脑为入口的网页叙事解谜游戏。剧情与关卡试玩版 **v0.4**。

试玩：https://vvvvvjdy.github.io/building-7-2008/

使用静态服务器打开目录即可，无安装和构建步骤：

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

## 文件

- `index.html`：桌面、窗口与任务栏。
- `game.js`：证据门槛、密码、存档与主线事件。
- `interface.js`：各章节的旧式软件界面与辅助交互。
- `story.js`：v0.4 开场、缓存路线、私人备份、原始材料、证据关联与终幕。
- `style.css`：XP Luna 风格、章节视觉、手机适配。
- `story.css`：v0.4 新增页面、资料来源标识与手机线索入口。
- `assets/`：本地图片；生成方式和完整提示词见其中的 README。

## v0.4

开场明确为刘可阳在自己的 2026 年电脑上打开旧移动硬盘。档案模拟 XP 与他的旧 QQ，星星进入他自己的空间；林夏头像经资料、关闭页、缓存目录进入她的空间。注销状态由后期整理者补录。

聊天口令 081231 指跨年看烟花的约定。栀子花只锁林夏的私人备份，公开论坛可直接访问；私人收藏索引用于寻找删除帖的本地快照。掌机统一为林夏的 NDSL。

八道谜题依次涉及聊天日期、私人备份、关键词与快照、合影对照、排放关联、诊断与款项、数据库恢复、五份事故材料配对。动机、已知风险、到场位置、具体行为和事故后果分别需要对应材料。材料均为虚构故事档案。

原始档案、缓存残缺和后期整理附注分开标注。录像、去世、寄出和送达日期分别为 2026-11-20、12-05、12-29、12-31；档案室同事按嘱托寄出，回应由预录与脚本触发。终幕目前使用文字转录，视频尚未接入。

v0.4 使用独立存档 `building7.demo.v2`，保留旧版存档。已在 Chrome 走通八道谜题、两种结局、八条证据，检查错误输入、全角日期、先论坛后补密码、刷新恢复、回收站重访及照片键盘操作；390px 手机空间、论坛和事故配对页检查无横向溢出。其他设备仍需组内试玩。

## v0.3 视觉基础

按团队第二阶段草图扩展旧硬盘资源管理器、QQ 空间、聊天消息管理器、博客、论坛列表与帖子、照片图层查看器、厂区文档、诊所档案、回收站、保卫科数据库、蓝屏和书信终幕。新增空间栏目、日记阅读、帖子收藏、聊天查找、笔记、时间线、数据库筛选、可拖动窗口、原创合成旋律和可选 CRT 扫描线。

该版本使用 `building7.demo.v1` 本地存档。所有输入、收藏、笔记和结局选择都只保存在当前浏览器；没有向真实 QQ、论坛或网络发送信息的功能。

已验证桌面全流程、两种结局、8 条证据、错误答案反馈、照片键盘操作、笔记刷新恢复、窗口控制，以及 390px 手机空间、论坛、文档页面无横向溢出。

仍为较短试玩原型：正式证据美术、视频自白与完整 90–100 分钟剧情尚未制作。不要将内部讨论记录或身份凭据提交到公开仓库。
